Meadow Design System

Components

Meadow ships six base components. Every one uses Meadow Green (#2F6B3F) for its main action, Bark (#1E2B20) for words, and an 8 point corner radius.

Pebble Button

The main action. Variants: Solid (green fill, white words), Outline (green edge), Quiet (words only). States: Rest, Hover, Pressed, Disabled.

Petal Chip

A pill that filters a list. States: Unselected (pale green edge), Selected (green fill with a check).

Reed Switch

Turns a setting on or off. States: On (green track), Off (grey track), Disabled.

Brook Field

A text field with a label above it. States: Empty (placeholder), Filled, Focused (green edge), Error (red edge and a message below).

Lantern Banner

A full width message at the top of a page. Tones: Info (blue), Warning (amber), Success (green).

Acorn Badge

A small count or status mark. Kinds: Neutral, Count, New.
