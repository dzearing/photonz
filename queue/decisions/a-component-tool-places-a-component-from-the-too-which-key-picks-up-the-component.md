# Which key picks up the Component insert tool?

## What the tool is

When you design a screen in Photonz (New Window, then the **Design UI** tile),
the tool bar holds the tools for building screens: Select, then Frame,
**Component insert**, Shapes, Pen and Text, then Measure. Component insert is
new. Pick it up, click the canvas, and a copy of a component (a Button, a Card,
one you made yourself) lands centred on your click, linked to its original. A
small capsule above the tool bar says which component the next click places,
and you can swap it there or by picking a tile in the Library.

The mock it comes from is the UI design walkthrough, step 4:
http://127.0.0.1:8791/index.html#ui-entry-wt (the purple four-diamond button
after Frame, with the tip "Component insert (C)").

## The question

The mock gives the tool the letter **C**. In Photonz, as in Photoshop, **C is
Crop**, and Photonz keeps one letter for one tool everywhere: a key you learn
never changes depending on the window you are in. So the mock's letter and the
house rule collide, and the choice is yours.

## The options

**A. N everywhere, C stays Crop (recommended, and what is built now).**
The tip reads "Component insert N". Pressing N anywhere picks the tool; C
always crops. Photoshop leaves N unassigned and nothing in Photonz uses it.
The cost: the mock says C, and N is not a mnemonic for component.

**B. C in Design only.** In the Design mode C picks the component tool, as
drawn; Crop (which sits under More in Design) has no letter there. Everywhere
else C crops and the component tool has no letter. The cost: C does two
different things depending on the mode, which is the kind of key that teaches
people to stop trusting shortcuts.

**C. Q everywhere, C stays Crop.** Like A with a different letter. It keeps N
free for the prototyping Connect tool the mocks give N to. On a video, while
the timeline has the keyboard, Q stays Premiere's ripple trim, the same sharing
L, I and O already do. The cost: Q is Photoshop's Quick Mask.

## Worked example

You are laying out a login screen in Design and want three buttons.

- Under **A**: press N, click, press N, click, press N, click. Later, in a
  screenshot, C crops it as always.
- Under **B**: press C, click, three times. Later, in Design, you press C
  meaning to crop a pasted screenshot and get the component tool instead.
- Under **C**: press Q, click, three times.
