# Where do you work the grid from?

## What changed

The grid is the set of lines you can switch on over a picture and snap to. Until
2026-09-29 it had its own section at the end of the floating tool bar: an icon
that opened its settings, a button reading the cell size, and a gear for Adjust
Grid (placing where the grid starts and pinning guides). You asked for that on
2026-09-06: "the way into adjusting the grid is buried in a menu. Move the work
to the tool bar."

On 2026-09-29 you asked for one information architecture, modelled on
professional Mac editors, where the tool bar holds only tools and zoom and view
options live in the View menu, the keys and the pinch, "never a control in a
bar". The grid is a way of looking at the picture, so it left the tool bar:

- **View, Grid** (Cmd ') shows and hides it, as before.
- **View, Grid Settings** opens the same settings, which now also carry the
  **Cell** size as a row.
- **View, Adjust Grid** takes the canvas over to place the zero point and pin
  guides. Its bar still has the cell size button, Clear Guides, Cancel and Done.

## Your two choices

**Keep it in the View menu (recommended).** The tool bar is only tools. Picking
a cell size takes View, Grid Settings, then the Cell menu. Photoshop, Pixelmator
Pro and Keynote all put the grid here.

**Put it back on the tool bar.** The icon, the cell size and the gear return to
the end of the bar whenever the canvas has room, and the placement contract
names the grid as the one thing on the tool bar that is not a tool.
