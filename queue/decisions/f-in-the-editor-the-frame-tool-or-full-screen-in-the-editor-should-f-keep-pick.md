# F in the editor: the Frame tool or full screen?

## What this is about

Photonz windows that hold a video have two modes. **View** is a plain player:
the picture, a slim transport bar under it, nothing else. **Edit** is the whole
editor: the tool bar, the timeline and the panel. A picture is always the editor.

On 2026-10-11 you asked for **F to put a video full screen** while you watch it,
the way video players do. That is now built: in the player, F fills the screen,
F or Escape bring it back, and View > Enter Full Screen (Control Command F, the
Mac's own key) works in every window.

In the **editor**, F still picks the **Frame tool**. The question is whether it
should also fill the screen there.

## Why it is a question

- **Photoshop** uses F to step through its screen modes (one of which is full
  screen), and puts its Frame tool on **K**.
- In Photonz, **K is the Lens tool**, so giving the Frame tool Photoshop's key
  means Lens gives it up.
- Editors usually reach full screen with the Mac's Control Command F, which
  already works everywhere.

## What you would see under each option

**A. F stays the Frame tool in the editor (recommended).** Nothing changes in
the editor. While watching, F fills the screen; in the editor, Control Command F
or View > Enter Full Screen does. Picking this retires the question.

**B. F is full screen everywhere; Frame moves to K; Lens has no key.** F fills
the screen in the player and the editor, pictures and videos alike. The Frame
tool's tip says K. Lens is picked from the tool bar, with no letter.

**C. F is full screen everywhere; Frame has no key.** Same as B for full screen,
but Lens keeps K and the Frame tool is picked from the tool bar with no letter.

## Worth knowing

The player has no tools at all, so F there can never pick a tool by surprise,
whichever option you choose.
