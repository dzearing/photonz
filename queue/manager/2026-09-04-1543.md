## Findings

### Objective gap
- **A copy cannot be resized.** The capture taken this pass shows a selected
  copy with X and Y live and W 78 / H 36 greyed. It is enforced in the model:
  `canSetGroupLayout` and `ownsContentRules` refuse an instance, and every sync
  writes `group.layout = main.group?.layout`, so a copy's size is the original's
  forever. The spec's own "Not in this slice" paragraph parked this waiting on
  an override that survives the sync, and the colour knob built exactly that
  machinery today. Task `a-copy-can-be-given-its-own-size` (p1).
- **Nothing can fill a stack along the way it runs.** `GroupFlow.stacked()`
  takes each piece's size straight from its own box on the flow axis and never
  reads that axis' rule, so a search field cannot grow with the nav bar holding
  it. The cross axis already does this with `.stretch`. Task
  `a-piece-can-take-the-room-a-row-has-left-over` (p2).
- **A component cannot hold a second version of itself.** The knob kinds are
  wording, show or hide, a shape choice and a colour; a disabled button is a
  second component made by hand. `objectives.json` names variants in this epic
  and `ui-building.md` defers states outright, so the plan and the objective
  disagree. Task filed and blocked on a card, below.
