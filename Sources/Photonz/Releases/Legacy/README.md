# Legacy

Reserved, and empty on purpose.

Legacy is what today's Current becomes when Next is promoted: Next becomes
Current, Current is demoted here, and people who depend on the old behavior are
not yanked out from under it.

Until that promotion there is nothing to run, so there is no `.legacy` case in
`Release` and the Experiments dialog lists two releases. When the day comes:
add the case, add `LegacyExperience` beside this file, and move the forked
Current files into this folder.

Nothing here is ever ported forward or back. Legacy is frozen by definition.
