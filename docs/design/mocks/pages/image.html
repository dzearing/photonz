The idea

Color editing is just layers. Add a Hue/Saturation, Curves, Color balance, or White balance adjustment layer above the pixels · it recolors everything below it, stays reorderable, and never touches the original.

One selection, three places

The ring on the canvas, the highlighted row in Layers, and the Properties group are the same adjustment layer. Tool options live at the top of Properties, so there is no options bar to learn.

Components anywhere

That gold Badge is the very same component from UI design, re-painted with a Style and stamped on the shot. It comes from the Library group in the dock. Open in the design system →

Automation

"Recover the shadows, mask the sky, remove the background" becomes a handful of the same API calls · every control here is one call, so the agent can do it too.
