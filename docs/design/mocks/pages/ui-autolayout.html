Auto-layout in the API

Every control in the Properties group is one field on the model
// the Properties group is just a friendly face on the model
frame.layout = { dir: "row", gap: 8, pad: 16, align: "center", distribute: "between" }
frame.children[1].grow = "fill"  // hug · fill · fixed
frame.add(component("Tag"))      // frame reflows on its own

The same command runs whether you drag a control, script it, or ask the agent. Auto-layout means you never hand-place a child. You describe the rule once and the frame keeps it, on UI, a photo, or a video title card.

The idea

An auto-layout frame is a flex container with intent. Set direction, gap, padding, alignment, distribution once and every child obeys. Change the content and the frame reflows on its own, so a design stays correct instead of drifting out of alignment.

A direction

Per-child hug / fill / fixed is the whole trick. Hug sizes to content, fill soaks up free space, fixed pins a size. Nest frames inside frames and a responsive layout falls out with no absolute coordinates anywhere.

Open question

Should gap and padding bind to spacing tokens by default so a whole file restacks when the scale changes, and should wrap be a fourth direction or a property on row and column?
