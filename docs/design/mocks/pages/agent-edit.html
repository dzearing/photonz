The idea

Select a real element, ask in plain language, and the agent answers with a readable diff · every property change shown before to after, previewed as a ghost on the canvas before anything sticks. Accept applies it, Undo takes it back.

Direction · one edit, one call

The edit is the same API the inspector calls, so it lands as a single undoable step in history · agent.edit(selection, "…") emits set(node, {…}). Local Qwen by default, a frontier model via MCP when you want more. No special mode, no baked pixels.

Open question

When a change touches many nodes, do you review one combined diff, or step through each node's edit with its own accept · and should a rejected diff leave a note the agent can learn from next time?
