    the Photonz menu, third group

    the front door opens: a prompt bar for the agent, four starting points, and your recent documents. Still no document, and the window says so: it has no canvas, no tool bar, no dock.

  3. 3

    the front door, under Start a project

    the tile is picked and the primary action now reads New UI canvas. A workspace is only a starting template chosen here, never a mode you will toggle later.

  4. 4

    the front door's title bar, right where document actions always sit

    an editor window opens behind the front door: untitled-ui · 1280 × 800, seeded with a Login starter frame, the UI tool strip, and the one right dock. The template gave you real layers, not a wizard.

  5. 5

  7. 7

    the Library's Components grid, in the right dock

    the component lands as a live instance: the purple ring and badge on canvas, a marked row in Layers, and Properties showing its variant and label. From an empty desk to a designed screen in seven clicks.

The idea

Every surface starts from the same blank slate: the resident menu-bar agent. For UI the entry is New Window → a template tile → a real canvas, and the template's only job is to seed honest layers. After that it is the ordinary shell: same Layers, same Properties, same Library as a photo or a cut.

A direction

The front door's prompt bar could take the same journey further back: describe the screen and the agent seeds the starter frame itself, then you keep designing by hand from layer one.

Open question

Should the front door close the moment a document opens, as shown here, or stay behind the editor so a second New is one click away? Closing is calmer; staying is faster for batch starts.
