The idea

A brush is data, not a black box. Tip shape, spacing, scatter, dynamics, and media are all numbers, and they live in Properties like any other selection, so designing a brush feels like direct manipulation instead of guesswork. Paint with it in Draw →

Direction

This is the Brush tool with its panel open, not a separate app. Presets sit in the Library group with scope set to Brushes, exactly where the brush library keeps them, and pressure and tilt map through an editable curve rather than a fixed on or off.

Open question

Should the preview simulate a chosen input, a mouse, a light pen stroke, a heavy one, so you can proof the dynamics before you commit, and should the agent be able to reverse engineer a brush from a photo of a real mark?
