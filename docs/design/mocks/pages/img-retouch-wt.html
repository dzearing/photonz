  1. 1

    the Heal tool

    the floating tool bar, under the canvas

    Heal becomes the active tool, Properties switches to its brush options, and a fresh Heal · spots layer appears above Base · RAW so the repair has somewhere to land.

  2. 2

    over each blemish on the cheek and forehead

    the canvas, with the Heal brush

    the spots are gone. Heal sampled clean skin next to each one and matched its texture, tone, and lighting. Every repair sits on the Heal · spots layer.

  3. 3

    the Clone stamp

    the floating tool bar, two slots along from Heal

    Clone takes over, Properties swaps to its options, and a Clone · texture layer joins the stack. Same tool bar, same slot, different job.

  4. 4

    from the source crosshair onto the stray hair

    the canvas. ⌥-click first to set the source

    real skin texture is copied over the stray hair, and the dotted link shows the offset the source keeps as you paint. It builds up on Clone · texture, not on the original.

  5. 5

    the panel menu

    the Layers group header, in the right dock

    the layer commands open: new retouch layer, frequency separation, group. Every panel group carries its own menu in the same corner, so you learn the position once.

  6. 6

    Frequency separation…

    the Layers panel menu you just opened

    the skin splits into Freq · color and Freq · detail, two adjustment layers that clip to everything below. Tone evens out; the pores stay exactly where they were.

  7. 7

    Dodge and burn

    the floating tool bar, next to Clone

    a Dodge & burn layer is added as 50% gray on soft light, and Properties shows its range and exposure. Nothing on the canvas has changed yet.

  8. 8

    along the cheekbones, nose bridge, and jaw

    the canvas, with Dodge and burn

    the face gains depth: the plus marks show where light was added, the minus marks where it was pulled back. It is all paint on the gray layer, so a lower opacity dials the whole thing back.

  9. 9

    Before / after

    the canvas actions cluster, top right of the canvas

    the divider drops in and the left half falls back to the untouched Base · RAW. Heal, Clone, the two frequency layers, and Dodge & burn each stayed on their own row, so any one of them can be dialled back or switched off months from now.

The idea

Retouching is not a mode. It is the ordinary shell with the image tool inventory in the floating bar, and each move adding one layer to the same stack. Because a filter is just a layer, frequency separation shows up in Layers next to a paint layer and clips to what is below it.

A direction

Save the whole stack as a reusable retouch recipe in the Library at scope Styles. Drop it on the next portrait and it re-fits to that face, every layer still there to nudge. The agent can run the recipe and hand you the layers to finish by hand.

Open question

Every step here is one API call (tool.heal, layer.frequencySplit, view.compare), so an agent could run the pass. How strong should its defaults be, given a believable portrait keeps pores and asymmetry?
