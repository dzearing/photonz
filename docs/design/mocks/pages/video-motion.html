In the API

The idea

A title sequence is a reusable component, not a one-off render. Drop it on any timeline, re-theme it with a Style, and the same stagger, path and easing come with it. Change the main once and every animated instance follows.

A direction

Text on a path, staggered reveals and kinetic emphasis are all just properties on one keyframe engine · the very engine the video timeline uses. Nothing here is a special motion mode; it is the same keys, plotted on the same time axis, in the same dock.

Open question

Should presets like stagger-up expose the offset as a single number, or a full per-word curve? The single number is fast and legible; the curve is precise but asks more of a first-time editor. The same call an agent makes should stay this simple.
