Specimen

The reuse tier

Tokens Styles Components Systems

Tokens

Named primitives: color, type, spacing, radius. The atoms everything references.

Styles

Named bundles of tokens: a text style, a fill, an effect. Edit once, every use updates.

Components

Reusable layer trees you instance and re-paint with Styles. Instances are linked to the main.

Systems

A named set of Tokens, Styles and Components. Swap the active system and every component re-resolves.

From a prompt

Describe the outcome and the agent runs the same commands you would, from the same command schema.

The idea

Everything the UI does is one command. Tool strip, context menu, the compact command surface and the ⌘K palette all reach the same call, so an agent drives the identical actions. That is why a filter can drop on a UI frame and a component can drop on a video track.
