Resizable panes

· Design language Design language

A resizer is the thin draggable divider between two docked panels. Reach for it whenever the split between panels is a matter of taste rather than a fixed layout: let people trade Layers width for canvas, or pull a timeline taller, and remember the choice. It respects a min and max, snaps to sensible widths, resets on double-click, and moves from the keyboard.

05

Rules

Keep panels usable at every size
Enforce a min width that keeps the header and its first control readable, never a bare edge. Highlight the divider on hover and focus so it clearly reads as draggable. Persist each pane size and offer a one-key reset layout back to defaults. Let a pane shrink until its content clips or its title disappears. Hide the resizer so users hunt a 1px line, or make the hit area so wide it steals clicks from content.
06

In the API

Every drag is a value an agent can set
Set a sizepane("layers").size = 232 clamps to the pane's min and max, then persists with the document.
Resetlayout.reset() returns every pane to its default, the same as double-clicking each divider.
Snap pointspane.snaps = [176, 232] makes a drag land on the nearest within 8px.
Read it backpane("timeline").size lets the agent reason about the same layout you see.

Keyboard. Focus a divider and nudge it without the mouse. This is the whole point of "everything the UI does is one API call": the resize you do by hand, an agent does with pane.size.

07

Responsive

What happens in a narrow window

When the window gets too small to honor a pane's min, the smaller pane snaps shut and remembers its last width. A thin reopen tab stays on the edge, so nothing is lost. The divider itself never disappears, and the panel it hid reopens at exactly the size you left it.

The idea

A resizer is a negotiation, not a slider. It hands people control of the split while quietly protecting both panels with a min, a max, and snap points, so the layout can flex without ever breaking.

A direction

Sizes are remembered per document today. They could ride on a workspace preset instead, so a "Retouch" layout and an "Edit video" layout each carry their own pane widths and you switch between them with one command.

Open question

Should a divider double as a collapse toggle? Dragging a pane to its min could latch it closed, but that risks people hiding a panel by accident. Maybe collapse only past a deliberate over-drag, never at the min itself.
