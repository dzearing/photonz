The idea

One front door for every scenario. Start tiles map to the three workspaces · Design UI · Image · Video · plus the fast redline path, all sharing the same primitives.

Direction

The prompt bar up top makes creating from a sentence the headline. It is not a second agent: Ask and ⌘K open the same conversation here that they open in a document window, so there is one agent with one surface, reachable from every window.

Open question

Recent is now the same filmstrip the history overlay uses, so a capture looks the same and offers the same actions wherever you meet it. That sharpens the remaining question: this window has no canvas, no tool bar and no dock because it holds no document. Is a launcher window the right shape, or should New and Recent live entirely in the menu-bar agent and the history overlay, so there is exactly one kind of window?
