The idea

One front door for every scenario. Start tiles map to the three workspaces · Design UI · Image · Video · plus the fast redline path, all sharing the same primitives.

Direction

Prompt bar up top makes automation the headline. Alternative: demote it once you're a returning user so recents lead.

Open question

This window has no canvas, no tool bar and no dock because it holds no document. Every other window in the study is the editor shell. Is a launcher window the right shape, or should New and Recent live entirely in the menu-bar agent and the history overlay, so there is exactly one kind of window?
