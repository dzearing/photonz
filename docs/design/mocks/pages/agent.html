Direction C · inline ghost

Draw a region, prompt where the content goes, and the agent fills it in place. Most spatial and most direct; pairs naturally with A or B for refinement.

What it costs

One more entry in the tool strip, which is where every tool already lives. The region itself is just a frame layer, so nothing new enters the model.

The point

Whichever wins, or all three, they call the exact same commands the UI does and reuse the same components and styles. Automation is the API made visible, not a bolt-on, which is why none of the three needed a single piece of new chrome.

Model-agnostic

The API is the contract, so the model is pluggable: a local Qwen (MLX / LM Studio) as the private, offline default; a frontier model via MCP when you want more. The schema keeps even a small local model safe, because only valid, undoable commands exist.

Open question

A and B both need a place to review what the agent proposed before it lands. Is that one shared Agent group that every direction feeds, or does each entry point get its own review affordance?
