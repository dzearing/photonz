In the API every step is one call
// outline the person, then cut run("select.subject") run("mask.fromSelection", { feather: 2 }) run("layer.removeBackground") // optional: drop a fresh backdrop run("background.fill", { style: "transparent" })

Every button on this page is one of these calls, so the agent can cut a subject from a plain sentence · local model by default.

The idea

Select subject outlines the person with a live marching-ants selection, Cut out drops the background to real transparency, and the subject lands on its own Layer · a checkerboard shows the alpha, exactly like a pro editor.

Direction

The cut is a non-destructive alpha mask, not a delete. Feather and Smooth re-shape the edge live · soften flyaway hair, tighten a hard shoulder · and a new backdrop is just another Layer underneath, swappable any time.

Open question

When a hair edge is genuinely ambiguous, should the refine brush ask for a quick scribble hint, or should it quietly propose a matte and let you nudge it? How much correction is worth a click versus a sentence to the agent?
