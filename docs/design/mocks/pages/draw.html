Draw and paint

· one shell · pen, brush, eraser · a vector path's stroke is a Brush

Pen, Brush, and Eraser are three tools in the same Draw shell, not three apps. And the Pen is the interesting one: its path stays exact, editable bezier geometry while its stroke is painted by a Brush. Drag an anchor and the brushed mark re-renders; close the path and you get a shape you can fill; swap the brush in the Library and the same geometry wears a completely different mark. The canvas is live, try it.

The idea

Vector and raster stop being separate. A Path keeps exact bezier geometry, and its stroke is painted by a Brush, so the structure is precise and the mark is expressive. Close the path and the same object also carries a Paint fill. Open the design system →

Direction

Because the brush is a Style and not baked pixels, restyling is one swap: pick a different brush in the Library group and every path drawn with it re-renders. That is the payoff for the agent too, since it emits precise coordinates and still gets a hand-drawn result. Brush presets live where the brush library keeps them.

Open question

Should a brushed stroke bake to pixels on export only, or should the app also offer a one-click rasterize so the mark can be smudged and blended like paint? And should the Pen auto convert a freehand brush stroke into an editable path on request?
