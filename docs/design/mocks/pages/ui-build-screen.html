The idea

A whole screen from frame, auto-layout, components, styles, content, preview, export, on one canvas in one window. The same five primitives that draw a photo or a video frame build a production UI, so there is no separate "UI mode" to learn.

A direction

Ship device presets as responsive variants of one frame, so a phone, tablet and desktop layout stay linked and repaint together when the Brand style changes.

Open question

When a dropped component already defines its own internal auto-layout, how should the frame's layout and the component's layout negotiate spacing without fighting each other?
