· usage clickthrough · exact geometry, expressive surface

Where vector and raster stop being separate things. You draw an exact bezier path, close it into a shape with a Paint fill, then paint its stroke with a Brush, so the structure stays machine precise and the mark looks hand made. The canvas below is live: the brush engine really stamps along the path, so swapping a brush or dragging an anchor re-renders in front of you. Nine real clicks on ONE screen, which never re-renders.

The idea

A path's stroke can be a Brush, so the usual choice between precise-but-sterile and organic-but-unrepeatable goes away. The geometry is exact and re-editable; the mark is expressive. Closing the path gives you a Paint fill as well, so one object carries both. Open the design system →

Why it matters for the agent

An agent emits exact bezier control points, which is what makes its output diffable and re-editable. Brushed strokes let it draw with those exact curves and still get a hand-made surface, and you can restyle everything it drew by swapping one brush.

Open question

Should a brushed stroke stay live forever, or offer a "bake to raster" once you are happy, so a very heavy illustration stops re-stamping on every nudge? And should the agent offer to clean a rough sketch into evenly spaced anchors?
