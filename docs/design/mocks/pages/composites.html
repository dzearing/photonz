A composite is a component built from components that you instance and re-paint. Both are just layers, which is why they live in the same tree, the same Layers group, and the same Properties group. The idea

Containers and composites are the same layer tree seen two ways. A container does auto-layout (direction, gap, padding, hug or fill). A composite is a component built from components you can instance and re-paint. Blue means layout, purple means reuse.

A direction

Bind a list container to data rows so cards generate themselves, one per row. Add a row, get a card. Every instance still links to the main Card, so a single edit ripples through the whole list and any Board that nests it.

Open question

When you detach one card in a data-bound list, should it keep its data slot or fully leave the list? And how far do overrides win before a design just wants to be its own component?
