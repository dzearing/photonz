Effects

· the non-destructive stack · the same rows on every layer

An effect stack is an ordered, re-editable list attached to a layer: glow, shadow, stroke, inner shadow, background blur. Nothing is baked into pixels, the order is meaningful, and the stack is identical whether the layer is a shape, a photo or a line of text. It is not its own screen, it is the Effects group in the one right dock, which is exactly where it sits below.

Try it

Toggle any switch in the Effects group and the card on the canvas updates live. Nothing is baked, so turning an effect off restores exactly what was underneath it.

One selection, three places

The ring on canvas, the Card row in Layers, and the Effects plus Properties groups are one selection. Effects are a property of the selected layer, not a separate editor.

API mirror

layer.effects = [glow(40, spread:6, paint:"Brand/gradient"), shadow(0,26,44)] · or layer.effectStyle = "Card glow".

A ladder, not six screens. Each rung is the same layer with one more row switched on in the same panel, which is the whole point of a stack: additive, ordered, and reversible at any rung.

1 2 3 4

1Drag grip · order is meaningful 2Enable · on or off, never deleted 3Name · click to edit its properties 4Readout · the live values

Every row in the stack has these same four parts, whether it is a glow, a stroke or a background blur. Learn the row once and the whole panel is readable.

Order matters (the same two effects, swapped)
Stroke over glowthe edge stays crisp and the glow sits behind it
Glow over strokethe glow washes over the edge and softens it

Two identical effects, two results, one drag apart. This is why the stack is a list you reorder rather than a set of checkboxes.

The idea

Ordered, non-destructive, and uniform across layer types. It generalizes today's LayerStyle: save a whole stack as a reusable Effect Style and every layer wearing it follows one source.

A direction

Let a stack row target a mask or a channel, so a glow can apply to just the alpha edge of a photo cutout. Same rows, one more slot, no new chrome.

Open question

Effects and adjustment layers overlap: a blur can be a row on a layer or a layer that clips to the layers below. Should the panel offer to promote a row into an adjustment layer when you want it to affect neighbours too?
