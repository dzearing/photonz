The idea

One command fans out into four on-brand options at once · each the same Poster component painted with your Brand style, differing only in accent and layout tokens. Pick the one you like, dismiss or regenerate the rest.

Direction · model-agnostic

Every option is the same command schema with different parameters · agent.variations(design, {count, vary}). Local Qwen (MLX) runs it privately by default; a frontier model via MCP when you want more. Same safe, undoable commands either way.

Open question

Should a kept option feed the next round · lock its layout and only reshuffle color · or should regenerate always explore wide from the original prompt? And do dismissed options teach the agent what to avoid?
