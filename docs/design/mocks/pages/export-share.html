One document, many outputs

The same file leaves as a PNG, JPG, PDF, SVG, or an MP4 when it moves. Pick a format and a scale and the summary shows the exact filename, pixel size, and a size estimate before anything is written to disk.

A link, not an attachment

Share hands back a real URL with a permission on it: View, Comment, or Edit. Copy it once and the same live document opens for anyone you send it to, no export step in between.

Specs are a view, not a file

Selecting an element reads its live measurements, colors, and the tokens behind them. Because styling is stored as settings, the panel shows --accent and space/s5, not a flattened hex guess.

Copy in the shape you need

Each group copies on its own: measurements as numbers, colors as hex or token, and the whole element as a CSS block. A developer takes exactly the piece they want without a hand-off document going stale.
