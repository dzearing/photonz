The idea

A mode is a set of values behind the same token names. Components reference accent, never a raw hex, so a mode switch re-resolves every token at once and the whole sample recolors in place.

A direction

Modes are not only Light and Dark. A Brand mode, a high-contrast mode, or a seasonal mode are all just more value columns for the same names, so any of them can be the active appearance.

Open question

When a layer pins a literal color instead of a token, should a mode switch leave it alone or offer to rebind it to the nearest token so it can follow the mode too?

In the API · the mode switch is one call, so the agent does it too

What the seg above actually does

1
Set the active mode. Every token re-resolves against that mode's value column. system.mode = "dark"
2
Read or edit one token's value for a single mode without touching the others. token("accent").value("brand")
3
Components keep referencing the name, so nothing per layer changes. The sample recolors because its tokens point at the mode.

The color picker in the map edits token("accent").value(mode) live. Reset restores the mode's shipped value.

token modesone call · same as the seg
// switch the active mode: every token re-resolves system.mode = "dark" // the name is constant, the value is per-mode token("accent").value("light") // "#4C6FFF" token("accent").value("dark") // "#7F9BFF" // edit one mode's value, leave the others alone token("accent").value("brand") = "#6E8BFF" // a component still references the NAME, not a hex button.fill = token("accent") // follows every mode
The idea

Because a mode is data, the whole switch is one property set: system.mode = "dark". Everything the seg does above is a call the agent can make too.

A direction

Bind a mode to context: preview Dark while your editor stays in Light, or auto-pick a mode per export target. The sample re-resolves without changing the document.

Open question

If two modes need different type or radius, not just color, should a mode carry any token, or stay color-only so appearance and layout never fight?
