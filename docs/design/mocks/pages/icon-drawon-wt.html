Draw a checkmark on

· usage clickthrough · one scenario

One job: when something succeeds, the success badge should draw itself rather than appear. Two things are different here from the other animation flows. Nothing moves, turns or scales: what changes is how much of the stroke has been drawn, which is a motion only a vector tool can offer and the one Photonz is closest to being able to do, because it already has the path and can measure it. And it is the first scenario with an order in it, which is where an icon starts wanting something time-shaped. The answer drawn here is a two row list with numbers on it, not a track, and the page says where a list would stop being enough. Seven real clicks on ONE screen, which never re-renders below.

The app has no answer for any of this yet. There is no motion on a layer and no SVG export, animated or still. The nearest thing that does exist is the vector model itself: this motion needs the length of a path and the direction it runs in, and both are things a pen tool knows. It is the cheapest of the four to build and the last one anybody would think of.

  1. 1

    the Ring layer

    the Layers group, at the top of the dock

    Properties opens with a Path section, and the first thing in it is a number nobody typed: this stroke is 56.5 units long. That measurement is the whole reason the next step is possible, and it is the sort of thing only a drawing tool has lying around.

  2. 2

    the Motion row, and look at the bottom group

    Properties, in the Motion section

    the same list of this layer's properties as every other glyph, with one heading that only a drawn shape gets: Path, holding Path points, Stroke width and Dash. Everything above that heading moves the shape around. These change the shape itself, which is a different kind of thing and worth a line between them. Drawing a stroke on is not a preset called Draw on, it is Dash going from all gap to all dash, and it is only offered because the path knows how long it is.

  3. 3

    Dash, and let it run from all gap to all dash

    the property list, under Path

    the ring draws itself round, over half a second, and the check is hidden for the moment so there is one thing to look at. Nothing moved, turned or scaled. Repeat came up as Once, unlike every other motion in the app, because a success mark that keeps redrawing is a success mark nobody believes.

  4. 4

    the From row, and choose The other end

    Properties, under Motion

    the ring sweeps anticlockwise instead, and a small marker appears on the artboard showing where the stroke begins and which way it runs. Every path has a direction because somebody drew it in one, and this is the first feature in the app that ever makes that visible. You should not have to guess it from the result.

  5. 5

    the Check layer, then Dash again, over 0.35s

    Layers, then the Motion section

    now there are two motions and the app has to say what happens when. An Order section appears: Ring at 0.00, Check at 0.50, whole thing 0.85 seconds. It is a list with real numbers in it, not a track with lanes, and for two shapes that is plainly enough.

  6. 6

    -0.08 in the Overlap field

    Properties, in the Order section

    the check now starts eighty milliseconds before the ring has closed, and the badge reads as one gesture rather than two animations played back to back. That is the entire craft of this scenario and it is one number. A ruler would have let you drag for it; a field lets you nudge it and watch, which is faster for a value this small.

  7. 7

    Ease out

    the Curve row

    both strokes now start quickly and settle, which is how a pen actually moves. At 16 the ring reads as a wipe rather than a drawn line, because there are not enough pixels in the stroke for the eye to follow a tip: the motion survives being small but it stops being the same motion. Worth knowing before it ships into a toolbar.

The idea

Drawing a stroke on animates the path, not the shape's position. It needs the path's length and its direction, which a vector tool already has and a video editor never would. Of the four animation scenarios this is the cheapest to build and the easiest to forget exists.

The honest bit

This is the first flow with an order in it, and order is the thing timelines are for. The answer drawn here is a two row list with real numbers and one overlap field, which is plainly enough for two shapes and plainly not enough for twenty.

A direction

The order list could stagger a whole group in one control: pick eight bars of a chart, say 40 milliseconds apart, and let the list fill itself in. That covers most of what people would otherwise open a timeline to do.

Open question

Where does the list stop being enough, and what replaces it? A track per motion is the obvious answer and it drags the whole video timeline in behind it. A nested sequence keeps the list but makes people think about grouping. This is the one question in the whole animation study that a comparison with the video flows should actually decide.
