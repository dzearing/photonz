The idea

The Library is one surface with four scopes, and it lives as a panel group in the one right dock. Set the scope to Components, search to narrow, click to pick up, then drop onto the canvas. Whatever lands is a linked instance, never a loose copy, so a single edit to the main updates them all.

A direction

Because it is a normal group, it collapses, resizes, and scrolls like every other panel, and the same content opens as a slide-down overlay when you want room to browse. The components themselves are defined in the design system, so the Library is a live view of that data.
