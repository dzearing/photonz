Make a bell swing

· usage clickthrough · one scenario

One job: the notification bell is already drawn, and it should swing when something new arrives. The first question the flow asks is the one every other animation mock skipped, which is what changes. Not a motion picked off a list of five, a property of this layer: its rotation, its position, its opacity, its colour, or the things only a path has. Motion is a list you add entries to, read exactly the way the list on the same layer is read, and the timing lives in a dock across the bottom where two parts of one icon can be seen against each other. Eight real clicks on ONE screen, which never re-renders below.

None of this exists in the app yet, and one part of it is harder than it looks. PhotonzCore has no notion of time, no keys and no motion on a layer, and nothing exports SVG at all. Rotation, position, scale, opacity and colour would interpolate the day a time model landed. Path points would not: two drawings can only be crossfaded point for point if they have the same number of points in the same order, and nothing in the app checks that or offers to fix it. The property menu below lists it anyway, and says so on the row, because hiding the hard one would make the model look tidier than it is.

  1. 1

    the Bell body layer

    the Layers group, at the top of the dock

    Properties fills in with three lists that read the same way: Appearance is what the layer is, Effects is what you add to it, and Motion is what changes over time. All three are empty-or-plus at the header. Nothing about animating is a mode you enter.

  2. 2

    the plus on the Motion header

    Properties, under Effects

    a list of this layer's own properties opens, each showing the value it has right now: Position 6, 4 · Scale 100% · Rotation 0° · Opacity · Colour · and, because this layer is a drawn path, Path points, Stroke width and Dash. There is no Pulse and no Spin in here. A named motion is a combination of these rows, which is a thing you make rather than a thing you pick off a short list somebody else wrote.

  3. 3

    Rotation

    the property list

    three things appear at once and they are the same one thing. A row in the Motion list, built exactly like an effect row: drag handle, switch, name, the curve drawn small, the values on the right. A bar on the timeline below, which is that entry's Start and Over. And a pivot on the canvas, because a rotation that does not say what it turns around has not been described yet.

  4. 4

    -12 and 12 into From and To

    Properties, in the Motion entry

    it starts moving, and it is wrong. The bell rocks about its own middle, so the top swings one way while the bottom swings the other and the whole thing reads as a bobblehead rather than a bell. Nothing about the numbers is wrong. The pivot is wrong, and until this page existed there was nowhere in the model to say so.

  5. 5

    the pivot from the middle of the bell up to the mount at the top

    on the canvas, with the pivot tool

    and now it is a bell. Same property, same two numbers, same duration: the only thing that changed is what it turns around, and it changed the motion completely. This is the step no preset could have done for you, because the right pivot is a point on your drawing and nobody but you knows where it is. It is a handle on the canvas rather than a hidden field, which is the whole reason the swing was fixable in one drag.

  6. 6

    the Curve row

    Properties, in the Motion entry

    a real list of curves opens, each one drawn beside its name, and it scrolls: linear, the four standard eases, sine, back, elastic, steps, and Draw a curve at the bottom. This is the correction to three buttons in a segmented control. The shape matters more than the name, so the shape is what you read.

  7. 7

    a handle in the curve editor until the swing hangs at the ends

    the Draw a curve popover

    the bell slows as it reaches each extreme and hurries through the middle, which is what a pendulum does and what no named curve is exactly. The readout is cubic-bezier(.45, 0, .55, 1), the same four numbers CSS and SVG take, so the curve you drew is the curve that ships. The row in the Motion list redraws its little sketch to match, so the list tells you the shape without opening anything.

  8. 8

    the Repeat row, and choose Forever

    Properties, in the Motion entry

    a dashed repeats line appears at 900 ms on the ruler, which is where this cycle ends and the next one starts. Notice what the ruler is: one cycle in milliseconds, not a document with a beginning and an end. That is the only shape that works for something that loops, and it is the surface the next page needs. The bell swings. .

The idea

Motion is a list you add entries to, one entry per property that changes, wearing the same row the Effects list already uses. Learning to add a border teaches you how to add a rotation, which is the consistency that a menu of five named motions can never have.

The pivot is the whole bell

A rotation with no origin cannot express the one animation anybody asks for. So the pivot is a handle on the canvas from the moment Rotation exists, not a field somebody has to know to go looking for, and step 5 is deliberately a repair: the motion is visibly wrong first.

Curves are drawn, not named

The list shows the shape beside every name and ends in Draw a curve, because a person can pick a shape by eye and cannot pick out back from out quint by reading. The readout is the four numbers CSS takes, so nothing is lost on the way out.

Why the timing is not in this column

Start and Over are in the side panel too, and for one entry that is enough. The bar across the bottom earns its width the moment there are two of them: is a relationship, and a relationship cannot be read in a column of numbers.
