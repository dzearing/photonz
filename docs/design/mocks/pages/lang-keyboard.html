Keyboard & shortcuts

· Design language Design language

Every action has a name and, where it earns one, a key. Shortcuts follow Photoshop so muscle memory carries over: single letters pick tools, ⌘ runs commands. Each key maps to exactly one named command, the same id the agent and the command palette use, so anything you can do by keyboard can be done by a call, and every binding is user-remappable.

Anatomy

A keycap renders one key. A shortcut row pairs a command name with its combo, right-aligned, so a column of them scans as a table. The row is the shared atom: menus, tooltips, and the palette all print the exact same combo.

States

A cap shows focus (accent ring, for keyboard users), pressed (accent fill, sinks 1px as the bevel flattens), and disabled (dimmed). A command that cannot run right now dims its whole row, combo included, so the reason is visible before you reach.

04

The legend

Grouped the way the menus are: Tools, Edit, View, Components. Tools take a bare letter, Photoshop's; edit and view take ⌘; the component tier (purple) stacks ⌥⌘ so it never collides with a familiar key.

Two tools that share one of Photoshop's groups share its letter, and the second one adds ⇧: Heal is J, Patch is ⇧J. That is the keystroke that actually reaches it, so a tool bar never prints the same key twice. Measure is I (Photoshop files the ruler with the eyedropper) because M is the marquee's.

Keep every tool one keystroke away.Let a new feature steal an established key.

API a category is just a menu: menu("View").items each carry their command and combo.

05

Modifier conventions

Each modifier means one thing everywhere. ⌘ runs, ⇧ extends, ⌥ alternates. Glyphs always print in the macOS order ⌃ ⌥ ⇧ ⌘, so a combo looks the same in a menu, a tooltip, and this legend.

Hold ⌥ for the "other" version of an action.Give one modifier two unrelated meanings.

API the parser normalizes order, so "shift+cmd+z" and "cmd+shift+z" bind the same.

Combo ⌘G Held together. Fires the instant the last key goes down.
Chord ⌘KthenB A leader, then a key. Opens a family: K B border, K S shadow.
Timeout ⌘Kthen… A hint bar shows the next keys; Esc cancels, no accidental fire.
06

Chord model

A combo is keys at once; a chord is a leader followed by a key, for a whole command family without burning a top-level shortcut. After the leader, a hint bar lists what is next, so a chord is discoverable, not memorized.

Surface the follow-up keys after the leader.Leave a half-typed chord armed with no way out.

API bind("cmd+k b", "effect.border") registers the sequence as one command.

07

Discoverability

You never have to memorize. The palette (⌘K) searches every command and prints its key; menus right-align the same combo; a tooltip shows a tool's letter on hover. Learn a shortcut by seeing it, three ways.

Print the combo beside its command, everywhere.Ship a command reachable only by a hidden key.

API the palette lists commands(); each item is { id, name, combo }.

// one key, one named command. the id the palette and agent share
bind("v", "tool.select")
bind("cmd+shift+z", "edit.redo")
bind("cmd+k b", "effect.border") // a chord

// the UI, the palette, and the agent all call the same id
run("tool.text") // == pressing T

// user remaps freely; conflicts are reported, not silent
keymap.set("edit.redo", "cmd+y")

08

In the API

A shortcut is a thin binding over a command id. bind(key, command) is the only mapping; the id is what the UI, the palette, and the agent all call. Because the key is not the command, every binding is remappable and a conflict is surfaced, never silent.

Route each key through one shared command id.Hard-wire behavior to a keystroke.

API run("tool.text") · bind() · keymap.reset() · see it in use.

Compact. In a narrow window the legend stacks to one column and menus drop to the small keycap, but a combo never wraps: the command name truncates first so the keys stay whole and readable.

The idea

Borrow Photoshop's keys so nobody relearns the basics, then make every command reachable from the keyboard through one shared id, so the fast path and the agent path are the same path.

A direction

Chords (a ⌘K leader plus a letter) could open deep families, effects, export presets, component ops, without spending scarce top-level keys, as long as the hint bar keeps them discoverable.

Open question

How far do we let people remap? A full custom keymap is powerful but drifts from the shared defaults an agent assumes. Do we ship a couple of trusted presets, or fully open remapping with one-key reset?
