Density & spacing

· Design language Design language

One 4pt scale is the app's whole sense of rhythm. Every pad, gap, margin, and inset resolves to a step on it, so unrelated surfaces still line up. Semantic tokens name the common jobs (pad a card, gap siblings, inset a window) and density shifts every one of them by a single step at once. This page is built only from that scale, so it is a specimen of the thing it documents.

The 4pt scale

Seven steps, drawn here at true size: 4 · 8 · 12 · 16 · 24 · 32 · 40. Nothing lives between them. Doubling early, then widening, keeps small controls tight and large layouts open.

Reach for the nearest step and stop.Invent a 7, 9, 11, or 13px value to "make it fit".

API exposed as CSS vars --s1…--s7; a command reads them by name, never a raw number.

Semantic tokens

Each job gets a name, not a number. Reach for the role (pad a card, gap siblings, inset a window) and the value comes with it. Change the role once and everything using it moves together.

Use --pad for a card, --gap between items.Hardcode 16 in fifty places you can never retune.

Anatomy of a card

A padded surface is three tokens: an even --pad ring on all four sides, a --gap-sm rhythm between its rows, and an --r4 corner. The tinted inset ring shows the padding is uniform, never lopsided.

Keep the padding equal on all four sides.Pad the top 16 and the sides 11 by eye.

API card.padding = "--pad" · card.radius = "--r4"; both are token refs, not pixels.

Density modes

Compact shifts every spacing token down one step in lockstep, so 16 becomes 12 and 12 becomes 8, and the layout tightens without a single new value. Type size and hit targets hold; only the air changes.

Switch density for power users on small screens.Hand-tune a few paddings to fake a compact look.

API density is a document preference ui.density = "compact". Narrow windows adopt it automatically.

Full-bleed & edges

Top-level blocks are full-bleed, with no side margins, so every window, caption, and toolbar shares one left and right edge. Alignment comes from a common grid, not from nudging each block by hand.

Let blocks span edge to edge and align by grid.Add a stray 9px margin that shifts one column.

API layout regions inherit the container edge; captions use flex:1 columns to track the grid above.

The idea

Spacing is not decoration, it is structure. One 4pt scale plus a handful of named roles means any two surfaces built months apart still align, and the whole app feels drawn by one hand.

A direction

Density could be smarter than a single toggle: a window under a threshold width auto-steps to compact, and an agent asked to "tighten this panel" just sets ui.density rather than editing pixels.

Open question

Do we ever need a step between 16 and 24 for mid-size gaps, or does adding a 20 quietly reopen the door to off-scale one-offs we spent this whole page closing?
