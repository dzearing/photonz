Pairing done right

Display in New York (a real macOS serif) over body in SF. The serif brings voice, the sans keeps reading effortless. Both live on the machine, so text stays crisp at any size.

Text takes Paint and Effects

The selected headline is filled with a Paint style and carries an Effect. Those are the same two rows a shape or a photo layer gets, in the same panel, in the same order.

API mirror

text("Made on a Mac", face:"New York", fill: style("Brand/gradient"), effect: glow(24))

The idea

Type is the fifth primitive. It pairs real macOS faces, carries Paint and Effects, and reduces to reusable Text Styles, the same reuse tier as color and components.

A direction

Lean fully into variable fonts: expose wght, opsz and wdth as animatable axes so a headline can breathe on scroll or across breakpoints, driven by one Style.

Open question

How far do we auto-apply optical sizing and wrap balance before it surprises people? Smart defaults are great until they quietly move a line the designer set on purpose.
