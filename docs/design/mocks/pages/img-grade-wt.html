One photo, one window, five real clicks. A grade is not a filter you bake in: it is a stack of adjustment layers above the untouched RAW, each re-reading the pixels below it. The window is rendered once and then operated, so you can see exactly where every control lives. At the end, click any eye in Layers to switch a layer off and watch the image change back.

The idea

A color grade is not a filter you bake in, it is a stack of adjustment layers sitting above the RAW. Exposure, Curves, HSL and Split tone each re-read the pixels below, so every move stays live and reorderable.

A direction

Because each layer is just a Layer with its own alpha mask, any step can be painted onto a region: warm the sky only, cool the water only. Save the four-layer stack as a reusable grade style in the Library and drop it on the next shot.

Open question

Should the default mask be per-layer, or one shared luminosity mask the whole stack references? Per-layer is more flexible but asks more of a first grade; a shared mask keeps a look consistent with one control.
