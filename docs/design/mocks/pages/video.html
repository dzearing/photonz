The idea

Video is not another app. It is the same document with a time dimension, so the shell is unchanged and only two regions are added: the transport bar and the timeline dock. The crux is a real keyframe editor plotted on the timeline's own axis, with draggable keys, visible easing, and a live value readout.

One selection, three places

Pick a clip on the timeline and the ring on the canvas, the row in Layers, and the Properties group all follow. The media pool is not its own widget: it is Library, scope Media, the same group that holds components and styles everywhere else.

Scope call · deferred

Basic video already ships (trim, crop, export). This timeline is its own later chapter, walled off so it never gates image and UI creation.

Open question

The keyframe editor sits inside the timeline dock so keys line up with frames. Should it instead be a panel group in the right dock, trading alignment for a taller canvas?
