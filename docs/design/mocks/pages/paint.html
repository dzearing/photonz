Paint

· the fill primitive · one editor, every surface

Paint is what fills a thing. Solid, linear, radial, angular, image or noise, it is one value with one editor, and it works the same on a shape fill, a stroke, a text layer and the color of a glow. It is not a separate mode or a separate screen: below is the real editor with a shape selected, and the Paint editor sitting where every other property sits, in the Properties group of the one right dock.

One selection, three places

The ring on the canvas, the highlighted Panel row in Layers, and the Properties group are the same selection. Paint is not a mode you enter, it is the Fill section of whatever you already selected.

Try it

Click a paint type in the Fill segmented control and the canvas repaints live. Linear, radial and angular keep the gradient ramp; solid and noise swap it for a single color row.

API mirror

fill: linear("#7C4DFF","#B14DFF","#FF5D8F", angle:135) · or once it is named, fill: style("Brand/gradient").

Paint types (six kinds, one editor, one value)
Solidsolid("#7C4DFF")
Linearlinear(stops, 135)
Radialradial(stops, 34% 30%)
Angularangular(stops, 200)
Imageimage(ref, fit:"cover")
Noisenoise(scale:5, mix:.4)

Every one of these is the same field on a layer, so switching type never loses the rest of the layer. A Paint can also carry an opacity and a blend mode, which is why "image" is a fill and not a separate layer type.

Gradient stop editor (anatomy)
1 2 3
1Stop · a color at a position 2Selected stop · edits below the ramp 3Track · click to add, drag to move

Double-click the track to add a stop, drag one off to remove it, and hold Option while dragging to duplicate. The same ramp edits a linear, radial or angular paint, only the geometry control below it changes.

Four slots, one value. That is what makes Paint a primitive rather than a feature of shapes: name it once as a Style and it can be the brand gradient on a button, on a headline, and in the glow underneath both.

The idea

Paint is the fill primitive: solid · linear · radial · angular · image · noise, one editor, every surface. Save any Paint as a named Style and it joins the design system.

A direction

Let a Paint reference tokens for its stops, so a gradient built from brand/500 and accent/400 re-resolves when a different design system is applied, instead of staying frozen hex.

Open question

Noise and image fills are procedural, so they can be expensive at large sizes. Should a Paint declare a render budget and fall back to a cached bitmap, or should that stay an automatic renderer decision the user never sees?
