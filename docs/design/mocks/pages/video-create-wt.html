The idea

The front door is global. Photonz sits in the menu bar, so the capture history is reachable with no window open, from the icon or ⌘⇧H. You never launch an app and then look for your recording. The editor is what a capture opens into, and the only thing a recording adds to it is time.

A direction

The timeline could be a fourth panel group that docks to the bottom rather than a fixed row, so a long multi-track edit collapses and scrolls with the same vocabulary as Layers and Library.

Open question

Every step is one API call (history.open, clip.place, clip.split, transition.add, export.mp4), so an agent could run the whole cut. Where is the line between guiding a person and doing it for them?
