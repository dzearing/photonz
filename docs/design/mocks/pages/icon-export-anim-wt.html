Hand the animated icon over

· usage clickthrough · one scenario

One job: the bell pulses, and now somebody else needs the file. Getting an animated icon out is not a format picker. The same animated SVG runs perfectly on a web page, is thrown away the moment a design tool imports it, and is stripped out of a README before anyone sees it. A list of formats cannot tell you any of that, so this sheet asks where it is going first and then says, in plain words, what survives the trip. Six real clicks on ONE screen, which never re-renders below.

Photonz exports no SVG at all today, animated or still, so all of this is a proposal. The constraints it describes are real ones though, not invented for the mock: a picture in an image tag runs its own CSS and SMIL but receives no clicks and loads nothing from outside itself, which is exactly why the toggle from cannot be handed over whole.

  1. 1

    Export, or press ⇧⌘E

    Properties, in the Hand-off section

    the bell is pulsing on the artboard and has been since you gave it motion. Export sits with the document, not in a menu you have to go hunting for, because handing an icon over is something people do ten times a day rather than once.

  2. 2

    the Where it is going row

    the export sheet, at the top of the right column

    the first thing the sheet asks for is not the format. It asks where the file is going, because that is the question that actually decides what happens to the animation, and because most people know their destination and do not know their formats. The preview beside it is running the real motion, not a still.

  3. 3

    A web page

    the destination list

    four honest destinations, and they behave completely differently. A web page is the good case: an animated SVG dropped into an image tag runs its own animation, stays sharp at every size, and still follows the surrounding text colour.

    A README on a code host

    the destination list

    the sheet changes its own answer. Code hosts sanitise uploaded SVG, so the animation would be stripped and often the picture with it. The format quietly moves to Video, the file name changes to match, and a plain sentence says why. This is a format picker knowing something about the world, which is the whole reason to ask about the destination at all.

  6. 6

    Export

    the bottom right of the sheet

    back on the good path, and look at the line under the list: the animated SVG is 1.2 KB and the same motion as a GIF is 74 KB, sixty times bigger and blurry at every size but one. Nobody asks for that comparison and everybody is pleased to see it. The file lands, and the pulse arrives with it.

The idea

Export asks where it is going before it asks what format, because the destination is the thing that decides whether the animation survives, and it is the thing the person already knows.

The line that earns the screen

Reacting to a tap does not survive. Saying that at export time, next to four things that do, is worth more than any amount of format detail. The rule it comes from is real: a picture in an image tag runs its own animation but receives no events and loads nothing external.

A direction

The preview could show the icon where it is going rather than on a neutral square: on a page, in a dark toolbar, beside a line of text at 14 points. That is the only way to catch an icon that is right on the artboard and wrong in place.

Open question

Should the sheet change the format for you when the destination cannot carry it, as drawn here, or only warn? Choosing for people is kind right up until it overrides something they set deliberately.
